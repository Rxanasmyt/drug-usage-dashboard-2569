วิธีนำ Dashboard ขึ้นเว็บให้ติดตั้งเป็นแอปได้

1) อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดในแพ็กเกจนี้ไปไว้ในโฟลเดอร์เดียวกันบนเว็บเซิร์ฟเวอร์
   (เว็บของ รพ., GitHub Pages, Netlify, Cloudflare Pages หรืออื่น ๆ)
2) เว็บต้องเปิดด้วย https:// (หรือ localhost ตอนทดสอบ) ระบบติดตั้งแอปถึงจะทำงาน
3) เปิดลิงก์ในมือถือ/คอม
   - Android (Chrome): เมนู ⋮ > ติดตั้งแอป / เพิ่มไปยังหน้าจอหลัก
   - iPhone (Safari): ปุ่มแชร์ > เพิ่มลงในหน้าจอโฮม
   - คอม (Chrome/Edge): ไอคอนติดตั้งที่ช่องที่อยู่เว็บ
4) ข้อมูลฝังอยู่ในไฟล์ data.js เป็นข้อมูล ต.ค. 2568 – ก.ย. 2569 ตามรายงานที่นำเข้า
   ไม่อัปเดตเอง เมื่อมีข้อมูลใหม่ต้องสร้างไฟล์ data.js ใหม่ แล้วเปลี่ยนเลข V ใน sw.js (เช่น drug-dash-v2)
   เพื่อให้เครื่องผู้ใช้โหลดข้อมูลใหม่

หมายเหตุ: ข้อมูลเป็นข้อมูลภายในโรงพยาบาล ควรจำกัดผู้เข้าถึงเว็บที่นำไปวาง
